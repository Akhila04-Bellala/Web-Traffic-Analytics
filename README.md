# Web Traffic Analytics

## Project Overview
This project analyzes website traffic data to understand visitor behavior, traffic sources, device performance, and user registration patterns.

## Objectives
- Analyze website sessions and pageviews.
- Measure bounce rate and session duration.
- Compare traffic sources and device categories.
- Analyze the registration conversion funnel.
- Identify high-performing landing pages and campaigns.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Key Findings
- Total sessions: 900
- Total pageviews: 3,108
- Average session duration: 243.49 seconds
- Bounce rate: 4.89%
- Total registrations: 166
- Overall conversion rate: 18.44%
- Google Organic generated the highest traffic.
- Instagram achieved the highest conversion rate among traffic sources.
- Desktop users had the highest device conversion rate.
- Career-week was the best-performing campaign by conversion rate.

## Project Files
- `Web_Traffic_Analytics_Report.pdf` – Final analysis report.

## Conclusion
The analysis provides insights into website visitor behavior and identifies opportunities to improve traffic quality, user engagement, and registration conversions.
